# MBA - WhatsApp Meta Cloud API (`mba_whatsapp_meta`)

Integración oficial de Odoo Community con la API Cloud oficial de Meta WhatsApp.

## Características
- **Cuentas WhatsApp:** Conexión con Meta Cloud API (Token de acceso permanente, Phone Number ID, WABA ID).
- **Gestión de Plantillas:** Sincronización automática de plantillas aprobadas por Meta, deduplicación de variables y mapeo dinámico de campos.
- **Conversaciones Bidireccionales:** Mensajería en tiempo real integrada con la app Conversaciones (`discuss.channel`) de Odoo.
- **Webhooks:** Recepción de mensajes entrantes, comprobantes/adjuntos, cambios de estado y verificación automática de Meta.
- **Control de Costos y Analítica:** Monitoreo de categorías Meta (Marketing, Utility, Authentication, Service) y tarifas asociadas.
- **Lista de Bloqueo (Blocklist):** Gestión de números bloqueados para cumplimiento y políticas de privacidad.
